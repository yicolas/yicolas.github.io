    Parameters

    § I
    %

    Guar gum mass % in the bank. Raises cohesion (τc) and lowers erodibility K exponentially. Expected range 0–5%.

    —m³/s
    u* shear vel
    — m/s
    U mean vel
    — m/s

    Derived from the initial geometry and held constant during the run: u* = √(gRS), U = u*/√Cf, Qw = U·w₀·H₀.

    —

    Bed slope (rise/run). Steeper S → deeper, faster flow, larger τ = ρgRS. Typical flume range 5e-4 to 5e-2.

    m

    Channel width at t = 0. Uniform erosion → w is a scalar in time.

    m

    Width of the rigid opposite wall. Once any cell's retreat reaches wmax, the bank has physically hit the wall and the simulation halts with a status message. Default 0.76 m for the physical flume being modeled.

    m

    Initial flow depth at the upstream end (x = 0). Qw is derived from (w₀, H₀) so the inlet starts in normal-flow equilibrium. Per-cell depth along the flume is then set by the backwater ODE integrated upstream from the baselevel BC.

    m

    Depth imposed at the flume outlet (x = L). Acts as the downstream BC for the backwater ODE. If Hout equals the cell's local normal depth the flow is spatially uniform; if higher you get an M1 backwater (pooling), if lower an M2 drawdown. The controller (below) will override this value when kmax exceeds kth.

    —

    Dimensionless tolerance on slope departure from equilibrium. The per-cell metric is ki = 1 − Sf,i/S. When max|ki| over all cells exceeds kth, the controller fires: Hout := Hin. Used when controller mode is "kth only" or "either".

    m

    Physical threshold on |Hin − Hout| — the depth difference between the upstream and downstream endpoints of the flume. When this exceeds dHth, the controller fires. Default 0.01 m (1 cm) to match the real operator's measurement resolution. Used when controller mode is "dHth only" or "either".

    How to decide when the controller fires. kth only: dimensionless slope-departure trigger. dHth only: physical depth-difference trigger (what an operator can measure). either: fire if either threshold is exceeded — most sensitive.

    m

    84th-percentile grain diameter in metres. Enters ks = 2.5·D₈₄ in Ferguson (2007).

    day

    Total simulated duration in days. Timestep dt = 60 s.

    Constants§ II

    kg/m³

    Water density. Appears in τ = ρgRS.

    m/s²

    Standard gravity.

    —

    Smooth-flow coeff (large R/ks).

    —

    Roughness-layer coeff (small R/ks).

    —

    Multiplicative fudge factor on the friction coefficient: Cf = (f/8)·kf. Use to tune the Ferguson law to match a specific flume's measured stage-discharge or roughness. kf = 1 (default) is the identity. Values > 1 increase friction (slower flow, lower Fr, steeper backwater curves); values < 1 reduce friction.

    Pa/%

    Slope of the τc vs GG% closure: τc = ατc·GG% + βτc. Controls how strongly guar-gum content raises the critical shear stress. Default 20.16 from Parker's calibration; experiment-specific calibration may need adjustment.

    Pa

    Intercept at GG% = 0. Represents the critical shear for non-cohesive bank material. Default 0.24 Pa.

    m·s⁻¹·Pa⁻¹

    Prefactor in K = K0·exp(βK·GG%). This is the zero-cohesion erodibility — the erosion rate coefficient a bank material with no guar-gum would have. Default 4.5×10⁻⁶.

    per %

    Exponent on GG% in K. Negative: more guar-gum → lower erodibility. Default −15.1, meaning each 1% increase in GG% reduces K by a factor exp(−15.1·0.01) ≈ 0.86 (about 14%). Set to 0 to disable the GG% dependence in K.

    Governing Equations

    § II
    Bank erosion closure Parker / excess-shear
    (1)τc = 20.16·(GG%) + 0.24critical bank shear stress (Pa)
    (2)K = 4.5×10⁻⁶ · exp(−15.1·GG%)erodibility coefficient (m·s⁻¹·Pa⁻¹)
    (3)E = K · (τ − τc),  else 0lateral erosion rate (m·s⁻¹)

    Classical excess-shear formulation. Both the threshold τc and the erodibility K respond to guar-gum content, but with opposite sign: GG% raises the threshold (more cohesion) AND lowers the rate constant exponentially — so a modest increase in GG% can effectively halt erosion even at high applied shear.

    Hydraulics & friction wide-channel, per cell
    (4)R = w·H / (w + 2H)hydraulic radius (reported, not used in τ or Cf)
    (5)τ = ρ g H Sboundary shear stress — wide-channel form
    (6)u* = √(τ/ρ) = √(gHS)shear velocity (m·s⁻¹)
    (7)ks = 2.5·D₈₄Nikuradse roughness height (m)
    (8)8/f = a₁²·a₂²·(H/ks)² / (a₁² + a₂²·(H/ks)^(5/3))Ferguson-style variable-power law
    (9)Cf = (f/8)·kf   [kf = 1.00]friction coefficient with user-set multiplier

    Wide-channel convention. τ, u*, and Cf are all written in terms of depth H rather than hydraulic radius R. This is the standard approximation for shallow, wide flows (H ≪ w) and is applied here by convention even though the flume has H ~ w. The trade-off: the model is internally self-consistent (no drift in the initial normal-flow state) but the shear stress is overpredicted by a factor ≈ H/R ≈ 3 relative to a narrow-channel computation at the default geometry. R is still computed as a reportable diagnostic.

    Initial-state Qw derivation t = 0 only
    (10)U = u*/√Cf  ⇒  Qw = U·w₀·H₀held constant for the run

    Qw is derived once from (w₀, H₀, S, D₈₄, a₁, a₂) so that Cf·Fr² = S exactly at the initial state. This makes (w₀, H₀) a true fixed point of the backwater ODE — the profile is flat at t = 0 with no numerical drift. After derivation Qw is frozen; only w and H evolve.

    Gradually-varied flow (backwater) spatial, subcritical
    (11)Sf = Cf·U²/(gH) = Cf·Fr²friction slope — wide-channel
    (12)Fr = U/√(gH)Froude number — gates criticality
    (13)dH/dx = (S − Cf·Fr²) / (1 − Fr²)backwater ODE, prismatic

    Prismatic-cell form. Eq 13 is the gradually-varied flow equation without the non-prismatic cross-term (Fr²·(H/w)·dw/dx) that would account for the channel widening along x. Each cell is treated as locally prismatic at its current w. This is a simplification relative to the full spec but is exact when dw/dx is small, and it removes a source of potential numerical instability.

    How it is solved. The flume is discretized into 400 cells of width Δx = 10 mm. Each timestep, given the current wi profile and the user's baselevel Hout as the downstream boundary condition, we integrate eq 13 upstream (i = N−1 → 0) using a trapezoidal predictor–corrector (Euler predictor + 3 fixed-point iterations per cell) to obtain Hi. The upstream sweep is the numerically stable direction for subcritical flow; if any cell reaches Fr ≥ 1 the (1 − Fr²) denominator is singular and the run halts.

    Why Hout matters. Hout enters only as the BC at x = L — it does not appear in the ODE itself. If Hout = Hnormal the profile is flat (uniform everywhere). If Hout > Hnormal you get an M1 backwater (pooling, H decreases upstream). If Hout < Hnormal you get an M2 drawdown (H increases upstream, approaching normal depth from below). Because τ = ρgHS, spatially non-uniform H drives non-uniform E, breaking the 0-D symmetry and making the 1-D model distinct from the scalar case.

    Temporal update forward Euler, dt = 60 s
    (14)wi(t + dt) = wi(t) + Ei·dtper-cell bank retreat

    Each cell widens independently at its own local erosion rate Ei. With the wide-channel τ the applied shear is larger than it was under the narrow-channel convention, so erosion rates are correspondingly higher at the same inputs. The CFL warning (E·dt/w > 5%) still applies.
